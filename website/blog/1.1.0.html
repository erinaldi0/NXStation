NXStation v1.1.0 — Library scrape, list art, screensaver

September 06, 2026 · v1.1.0 Latest draft

GitHub Releases

Documented here ahead of the GitHub release — check GitHub Releases for the downloadable NRO when it ships.

Update v1.1.0 is the recommended build if you are on v1.0.0 or earlier.

Website: https://nxstation.com Wiki: https://nxstation.com/wiki.html Blog: https://nxstation.com/blog/1.1.0.html Downloads: https://github.com/jiraiya78/NXStation/releases

What's new

  • Scrape Library (systems Y menu) — batch-scrape every real system in one run
  • Minus starts the screensaver from the system browser and game list
  • Screensaver keeps the screen bright for 30 minutes, then sleep can resume
  • List-style system art falls back to the carousel JPG when no -list file exists
  • Missing game descriptions stay empty (no dummy text)
  • Y menu no longer scrolls the system list behind the popup

Copy NXStation.nro to sdmc:/switch/NXStation/NXStation.nro. Title Override (hold R) is still required.
